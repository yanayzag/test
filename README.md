# PhishSim — כלי סימולציית פישינג פנים-ארגוני לחינוך עובדים

כלי **חינוכי** להעלאת מודעות לאבטחת מידע בארגון. הוא שולח לעובדים מייל פיתיון
מדומה ("מדיניות הבאת כלבים למשרד"), ומי שלוחץ על הלינק מגיע לעמוד שמסביר שזו
הייתה סימולציה — ונותן טיפים איך לזהות פישינג אמיתי בפעם הבאה.

> ⚠️ **זהו כלי הדגמה בלבד.** הוא **לא** תוקף, לא מתקין דבר, לא אוסף סיסמאות,
> ולא גורם נזק לנתונים/לתוכנה/לאנשים. הוא עוצר מיד אחרי שמוצגת ההתנהגות
> (הלחיצה) ומראה מסך חינוכי.

---

## ⚖️ שימוש אחראי — חובה לקרוא

הפעלת סימולציית פישינג על עובדים היא פרקטיקה לגיטימית ומקובלת, אבל חייבת
להתבצע נכון:

1. **הרשאה בכתב** — רק על עובדי הארגון שלך, עם אישור ההנהלה/בעל המערכת.
2. **דומיין משלך** — שלח מכתובת ושרת של הארגון בלבד. אל תתחזה לגוף חיצוני
   אמיתי (בנק, ספק, רשות). התחזות לגורם חיצוני עלולה להיות עבירה.
3. **פרטיות** — אסוף מינימום מידע (מי לחץ ומתי). הכלי לא שומר סיסמאות ולא
   מריץ קוד אצל העובד. יידע את העובדים מראש (בתקנון/אונבורדינג) שהארגון
   מבצע תרגולי מודעות מעת לעת.
4. **ללא "ענישה"** — המטרה חינוך, לא הפללה. דווח על תוצאות באגרגציה.

## התקנה

```bash
pip install -r requirements.txt
cp config.example.yaml config.yaml   # ערוך עם פרטי ה-SMTP שלך
cp recipients.example.csv recipients.csv
```

## הפעלה

**1. הרם את שרת המעקב** (מגיש את עמוד הנחיתה החינוכי ורושם לחיצות):

```bash
python app.py
# מאזין על http://0.0.0.0:5000  — חשוף אותו בכתובת פנימית של הארגון
```

**2. שלח את הקמפיין** — תמיד מתחילים ב-dry run (לא שולח באמת):

```bash
python send_campaign.py --campaign "dog-policy-oct" --dry-run
```

כשהכול נראה טוב, שלח בפועל (דורש הרשאה מפורשת):

```bash
python send_campaign.py --campaign "dog-policy-oct" --send
```

**3. צפה בתוצאות:**

```
http://<server>:5000/admin?key=<ADMIN_KEY מה-config>
```

## מבנה

| קובץ | תפקיד |
|------|-------|
| `app.py` | שרת Flask: מגיש עמוד נחיתה חינוכי, רושם לחיצות, לוח בקרה |
| `send_campaign.py` | שולח את מייל הפיתיון (dry-run כברירת מחדל) |
| `templates/email_dog_policy.html` | תבנית מייל הפיתיון |
| `templates/landing.html` | עמוד "נפלת לסימולציה" החינוכי |
| `templates/admin.html` | לוח בקרה עם אחוזי לחיצה |
| `config.example.yaml` | הגדרות SMTP, מפתח אדמין, הרשאה |

## בטיחות מובנית בקוד

- `send_campaign.py` הוא **dry-run כברירת מחדל**. שליחה אמיתית דורשת `--send`.
- שליחה חסומה עד ש-`authorized: true` מוגדר ב-`config.yaml`.
- עמוד הנחיתה הוא HTML סטטי בלבד — אין טפסים, אין איסוף סיסמאות, אין קוד שרץ
  אצל העובד.
