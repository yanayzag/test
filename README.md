פיתיון מדומה ("מדיניות הכלבים"), ומי שלוחץ על הלינק מגיע לדף חינוכי של קימי
שמסביר שזו הייתה סימולציה — ומלמד איך לזהות פישינג אמיתי.

> ⚠️ **הדגמה בלבד.** אין תקיפה אמיתית, לא מותקן כלום, לא נאסף מידע, אין
> איסוף סיסמאות. הדף עוצר מיד אחרי ההדגמה ומראה מסך חינוכי.

## מה יש כאן

| קובץ | תפקיד |
|------|-------|
| `index.html` | דף הנחיתה החינוכי של קימי (זה מה שמתארח ב-GitHub Pages) |
| `email.html` | מייל הפיתיון — להדבקה ל-Gmail של המנכ"ל |
| `assets/` | תמונות של קימי |

## איך מפעילים — 3 שלבים

**1. הפעל GitHub Pages** (פעם אחת) — כדי לארח את דף הנחיתה:
   - ב-GitHub: `Settings` → `Pages` → `Branch: master` (או `main`) → `/ (root)` → `Save`.
   - אחרי דקה הדף יהיה זמין בכתובת: `https://yanayzag.github.io/test/`

**2. שלח את המייל מה-Gmail שלך:**
   - פתח `email.html` בדפדפן, סמן הכול (Ctrl/Cmd+A) והעתק.
   - ב-Gmail: הודעה חדשה → הדבק → נמענים: העובדים → שלח.
   - הלינק במייל כבר מצביע לדף של קימי.

**3. זהו.** מי שלוחץ מגיע לדף החינוכי.

> אם שינית את שם המשתמש/הריפו ב-GitHub, עדכן את הכתובת
> `https://yanayzag.github.io/test/` בקבצים `email.html` ו-`index.html`.
