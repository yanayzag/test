# תרגיל מודעות לפישינג · ExperTeam 🦎

כלי **חינוכי** להעלאת מודעות לפישינג. המנכ"ל שולח מהמייל שלו מייל פיתיון
("מדיניות הכלבים"), ומי שלוחץ על הלינק מגיע לדף חינוכי של קימי שמסביר שזו
הייתה סימולציה. הדף מתארח ב-**GitHub Pages**, ו-**GoatCounter** סופר **כמה
אנשים הגיעו** — בלי מקצר קישורים ובלי דף ביניים.

> ⚠️ **הדגמה בלבד.** אין תקיפה אמיתית, לא מותקן כלום, לא נאסף מידע אישי,
> אין איסוף סיסמאות. הדף עוצר מיד אחרי ההדגמה ומראה מסך חינוכי.

## מה יש כאן

| קובץ | תפקיד |
|------|-------|
| `index.html` | דף הנחיתה החינוכי של קימי (מתארח ב-GitHub Pages) |
| `email.html` | מייל הפיתיון — להדבקה ל-Gmail של המנכ"ל |
| `assets/` | לוגו ExperTeam + תמונות קימי |

## איך מפעילים

**1. GitHub Pages** (פעם אחת) — `Settings` → `Pages` → Branch `master` → `/ (root)` → `Save`.
   הדף יהיה ב: `https://yanayzag.github.io/test/` (הריפו צריך להיות ציבורי).

**2. מונה GoatCounter** (פעם אחת):
   - היכנס ל-[goatcounter.com](https://www.goatcounter.com) → הירשם חינם → בחר קוד (למשל `experteam`).
   - תקבל לוח בקרה בכתובת `https://experteam.goatcounter.com`.
   - ב-`index.html` החלף את `YOURCODE` בקוד שבחרת (בשורת ה-GoatCounter, `data-goatcounter`).

**3. שלח מה-Gmail שלך:**
   - פתח `https://yanayzag.github.io/test/email.html`, סמן הכול (Cmd+A), העתק, הדבק להודעה
     חדשה ב-Gmail, ושלח. (הלינק כבר מפנה ישירות לדף.)
   - מומלץ לשלוח לעובדים ב-**Bcc**.

**4. צפייה בתוצאות:** היכנס ל-`https://<הקוד-שלך>.goatcounter.com` ותראה כמה ביקרו בדף.

- **4 דגלים אדומים**: זמן השליחה · יצירת תחושת דחיפות · ה-URL החשוד · סממני AI.
- למה פישינג זינק בעקבות AI, ושהמסנן של Microsoft חוסם הרבה אבל לא הכול.
- שאנחנו 40 עובדים, בלי משאבי אנוש ובלי אבטחת מידע — כל אחד הוא קו ההגנה.
