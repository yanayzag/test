# תרגיל מודעות לפישינג · ExperTeam 🦎

כלי **חינוכי** להעלאת מודעות לפישינג. המנכ"ל שולח מהמייל שלו מייל פיתיון
("מדיניות הכלבים"), ומי שלוחץ על הלינק מגיע לדף חינוכי של קימי שמסביר שזו
הייתה סימולציה. הלינק עובר דרך **Bitly** שסופר **כמה לחצו**.

> ⚠️ **הדגמה בלבד.** אין תקיפה אמיתית, לא מותקן כלום, לא נאסף מידע, אין
> איסוף סיסמאות. הדף עוצר מיד אחרי ההדגמה ומראה מסך חינוכי.

## מה יש כאן

| קובץ | תפקיד |
|------|-------|
| `index.html` | דף הנחיתה החינוכי של קימי (מתארח ב-GitHub Pages) |
| `email.html` | מייל הפיתיון — להדבקה ל-Gmail של המנכ"ל |
| `assets/` | לוגו ExperTeam + תמונות קימי |

## איך מפעילים — 4 שלבים

**1. הפעל GitHub Pages** (פעם אחת) — כדי לארח את דף הנחיתה והתמונות:
   - `Settings` → `Pages` → Branch: `master` → `/ (root)` → `Save`.
   - אחרי דקה הדף יהיה זמין ב: `https://yanayzag.github.io/test/`
   - (הריפו צריך להיות ציבורי כדי ש-Pages יעבוד בחינם.)

**2. צור קישור Bitly** שמצביע לדף:
   - היכנס ל-[bitly.com](https://bitly.com), פתח חשבון חינמי.
   - `Create` → הדבק `https://yanayzag.github.io/test/` → קבל קישור קצר (למשל `https://bit.ly/abc123`).

**3. הכנס את קישור ה-Bitly למייל:**
   - פתח `email.html` והחלף את `https://bit.ly/REPLACE-ME` בקישור שקיבלת.
   - (התמונות כבר נטענות אוטומטית מ-Pages — לא צריך לגעת.)

**4. שלח מה-Gmail שלך:**
   - פתח `email.html` בדפדפן, העתק הכול (Cmd+A), הדבק להודעה חדשה ב-Gmail, שלח.

**לצפייה בתוצאות:** היכנס לחשבון Bitly → הקישור שלך → מספר הקליקים.

## מה הדף החינוכי מלמד
- **4 דגלים אדומים**: זמן השליחה · יצירת תחושת דחיפות · ה-URL החשוד · סממני AI.
- למה פישינג זינק בעקבות AI, ושהמסנן של Microsoft חוסם הרבה אבל לא הכול.
- שאנחנו 40 עובדים, בלי משאבי אנוש ובלי אבטחת מידע — כל אחד הוא קו ההגנה.

## הערות
- Bitly סופר **סה"כ קליקים**. מערכות הגנה (כמו Microsoft Safe Links) לפעמים
  "לוחצות" על לינקים לבדיקה ומנפחות את המספר — קח אותו כמגמה, לא כספירה מדויקת.
- רק על עובדי הארגון שלך, מהמייל שלך. אל תתחזה לגוף חיצוני אמיתי. חינוך, לא הפללה.
