# תרגיל מודעות לפישינג · ExperTeam 🦎

כלי **חינוכי** להעלאת מודעות לאבטחת מידע. המנכ"ל שולח מהמייל שלו מייל פיתיון
מדומה ("מדיניות הכלבים"), ומי שלוחץ על הלינק מגיע לדף חינוכי של קימי שמסביר
שזו הייתה סימולציה — ומלמד איך לזהות פישינג אמיתי. השרת סופר **כמה לחצו**.

> ⚠️ **הדגמה בלבד.** אין תקיפה אמיתית, לא מותקן כלום, לא נאסף מידע אישי,
> אין איסוף סיסמאות. נרשם רק מונה קליקים + זמן. הדף עוצר מיד אחרי ההדגמה.

## מה יש כאן

| קובץ | תפקיד |
|------|-------|
| `index.html` | דף הנחיתה החינוכי של קימי (ממותג ExperTeam) |
| `email.html` | מייל הפיתיון — להדבקה ל-Gmail של המנכ"ל |
| `app.py` | שרת מעקב קטן: מגיש את הדף, סופר קליקים, דף `/stats` |
| `assets/` | לוגו ExperTeam + תמונות קימי |

## הפעלה

**1. הרם את שרת המעקב:**

```bash
pip install -r requirements.txt
STATS_KEY="בחר-סיסמה-סודית" python app.py       # מאזין על פורט 5000
```

כדי שהעובדים יוכלו להגיע אליו, השרת צריך כתובת ציבורית. לחברה בלי IT, הדרך
הכי פשוטה לחלון התרגיל היא מנהרה זמנית מהמחשב שלך:

```bash
# דוגמה עם cloudflared (או ngrok) — נותן כתובת https זמנית
cloudflared tunnel --url http://localhost:5000
```

לחלופין אפשר להעלות את `app.py` לשירות חינמי (Render / PythonAnywhere / Replit).

**2. הכנס את כתובת השרת למייל:**
   פתח `email.html` והחלף את כל המופעים של `https://your-tracker-url`
   בכתובת שקיבלת (למשל `https://abc.trycloudflare.com`).

**3. שלח מה-Gmail שלך:**
   פתח `email.html` בדפדפן, העתק הכול (Ctrl/Cmd+A), הדבק להודעה חדשה
   ב-Gmail, שלח לעובדים.

**4. צפה בתוצאות:**

```
https://<כתובת-השרת>/stats?key=בחר-סיסמה-סודית
```

תראה כמה אנשים לחצו (ייחודיים), אחוז מתוך 40 העובדים, וזמני הלחיצה.

## מה הדף החינוכי מלמד
- **4 דגלים אדומים** במייל: זמן השליחה · יצירת תחושת דחיפות · ה-URL החשוד ·
  סממנים של AI.
- למה פישינג זינק בעקבות AI, ושהמסנן של Microsoft חוסם הרבה אבל לא הכול —
  במיוחד במייל אישי.
- שאנחנו 40 עובדים, בלי משאבי אנוש ובלי אבטחת מידע — אז כל אחד הוא קו ההגנה.

## פרטיות ושימוש אחראי
- נשמר רק מונה קליקים + חותמת זמן. **לא** נשמר מי לחץ, לא IP, ולא סיסמאות.
- רק על עובדי הארגון שלך, מהמייל שלך. אל תתחזה לגוף חיצוני אמיתי.
- המטרה חינוך, לא הפללה — דווח תוצאות באגרגציה, אל "תעניש" מי שלחץ.
